# Rapls Sitemap

WordPress サイトに **読者向けの HTML サイトマップ**（サイトの目次）を作るプラグインです。固定ページは親子階層のまま、投稿はカテゴリー別に整理し、ショートコードかブロックを 1 か所置くだけでページが組み上がります。

検索エンジン向けの XML サイトマップではありません。XML は WordPress 本体が `wp-sitemap.xml` として出力するので、本プラグインはそこには手を出しません。

**PS Auto Sitemap**（2022 年に配布終了）と **WP Sitemap Page** の、メンテナンスが続く代替として作っています。どちらのコードも流用せず、公開されているインターフェースだけを再現しているため、サイトマップページの本文を書き換えずに乗り換えられます。PS Auto Sitemap の設定は、ボタン 1 つで読み込めます。

## Features

- **1 か所の設置で 1 ページ分** — 固定ページ・投稿・カテゴリー・投稿者・年月アーカイブを、それぞれの見出しを付けて順に並べられます。サイトマップページによくある形です
- **ナビゲーションメニューをそのまま目次に** — 運用者が組んだ順序とラベルのまま出力。複数のメニューを 1 ページに並べることもできます
- **黙って減らさない** — 件数上限に達した一覧は、必ず出力にその旨を明記します
- **デザインプリセット 27 種＋スタイルなし** — 画像・スプライト・アイコンフォントを一切使わない CSS のみの実装。テーマの色を継承し、ダークテーマでもそのまま使えます
- **大規模サイト向けの設計** — 投稿タイプごとに 1 クエリ、投稿・ターム・投稿者の 3 クエリすべてに効く件数上限、コンテンツ更新時に自動で破棄されるレンダリングキャッシュ
- **フロントエンドに開発者へのリンクを一切出しません**

### 一覧にできるもの

| 対象 | 内容 |
|---|---|
| 固定ページ | 親子階層のまま、任意の深さで |
| 投稿 | カテゴリー別に整理（子カテゴリーも入れ子） |
| カテゴリー・タグ・カスタムタクソノミー | 記事付き / ターム一覧のみ |
| 投稿者 | ユーザー ID とロールで絞り込み |
| 年月アーカイブ | 年・月単位 |
| ナビゲーションメニュー | メニューの順序とラベルのまま。`#` の項目は見出しとして出力 |
| カスタム投稿タイプ・カスタムタクソノミー | 標準のものと併用も、置き換えも可 |

### 絞り込み

- 階層の深さ制限、「この固定ページの下だけ」の範囲指定（ショートコードでは現在のページ、またはその親に解決可）
- 記事 ID・カテゴリー ID・ユーザー ID による除外。親を除外すれば子も一緒に外れます
- 投稿タイプ・タクソノミー単位の除外
- サイトマップを置いたページ自身、パスワード保護された項目、noindex の項目の除外
- 公開日による期間指定（年度別サイトマップ）。年月アーカイブ一覧とカテゴリー一覧も一緒に絞り込まれます
- 件数上限：1 リストあたり、カテゴリーごと、開始位置

### 並び順

- 記事 — 新しい順・古い順・タイトル順・ID 順・ページの並び順・更新日順・コメント数順・ランダム・カスタムフィールド順
- カテゴリー見出し — 名前・記事数・スラッグ・ID・手動の並び順（並べ替えプラグインと併用）。「記事数」は WordPress が保持する集計値で、除外設定を適用したあとにカテゴリーの横へ表示される件数とは一致しないことがあります

### デザイン

- プリセット 27 種＋「スタイルなし」
- 文字の大きさ・行間・字下げ・リンク色・下線・段組みを、どのプリセットの上にも重ねられます
- 箇条書きの記号 — 黒丸 / 白丸 / 四角 / 絵文字 / アイコンクラス（Font Awesome 等）。最上位と下の階層で別々に指定
- 見出しを `h2`〜`h6` の本当の見出し要素として出力（スクリーンリーダー対応）
- 下に項目を持つ項目を、リンクではなく見出しとして表示する設定
- 追加 CSS の記述欄（`unfiltered_html` 権限が必要）

## Installation

### WordPress.org から（推奨）

1. WordPress 管理画面 → **プラグイン** → **新規追加**
2. 「Rapls Sitemap」で検索 → **インストール**
3. 有効化後、**設定 → Rapls Sitemap** で表示内容を選択

### GitHub から

1. [Releases](../../releases) から最新版の ZIP をダウンロード
2. WordPress 管理画面 → **プラグイン** → **新規追加** → **プラグインのアップロード**
3. 有効化

## セットアップ

### 前提条件

- **WordPress 6.0 以上**
- **PHP 7.4 以上**

外部サービスへの接続も、API キーも必要ありません。

### 設置

サイトマップを置きたい固定ページに、次のどちらかを置きます。

```
[rapls_sitemap]
```

またはブロックエディターで「サイトマップ」ブロックを追加します。

### よく使う指定

```
[rapls_sitemap sections="page,post,category,author,archive"]
[rapls_sitemap menu="global-nav"]
[rapls_sitemap child_of="current"]
[rapls_sitemap date_after="2026-04-01" date_before="2027-03-31"]
```

`sections` は、指定した順にそれぞれの見出しを付けて並べます。`menu` はメニューの ID・スラッグ・名前のいずれかで、指定した時点でメニュー表示になります。

`child_of` は 2 つの語を受け付けます。`current` は貼ったページ自身に解決されるので、セクションのトップページに貼れば「そのページの下」の目次になります。`parent` は 1 つ上に解決されるので、**下層ページ共通のテンプレートに 1 つ貼れば、どのページでも「同じセクションの兄弟ページ」の目次**になります。親を持たないページでは、そのページ自身が解決先です（そのページがセクションの頂点だからです）。

## 他プラグインからの移行

移行用の互換機能は 2 つあり、**どちらも初期状態ではオフ**です。「設定 → Rapls Sitemap → 移行」で、移行元に合うものをオンにしてください。他プラグインの記法に勝手に反応しないための初期値です。

**WP Sitemap Page から** — `[wp_sitemap_page]` とその `only` 値（カスタム投稿タイプを含む）を認識します。WP Sitemap Page 本体が有効な間はショートコードを登録しないため、両方が有効でも競合しません。

**PS Auto Sitemap から** — 本文中の `<!-- SITEMAP CONTENT REPLACE POINT -->` を認識します。旧プラグインの「サイトマップを表示する記事」の ID 指定は不要です。そのページ自身は自動で一覧から除外されます。

**設定はボタン 1 つで読み込めます。** PS Auto Sitemap の設定はプラグインを削除しても残るため、以前使っていたサイトなら設定画面に「PS Auto Sitemap から読み込む」が現れます。表示するリストとその順序、階層の深さ、除外カテゴリー・除外記事、キャッシュの有無、そして近いデザインが入ります。旧設定は読むだけで書き換えないので、何度でもやり直せます。

旧プラグインの「カテゴリーと記事の表示」で「分割」を選んでいた場合は「カテゴリーのみ」として読み込みます。旧プラグインはカテゴリーの横に「このカテゴリーの記事を見る」リンクを出していましたが、本プラグインに同じ動きはないため、最も近い設定への読み替えです。

## noindex 連携

「noindex の項目を除外する」をオンにすると、次のプラグイン・テーマの設定を**追加設定なしで**読み取ります。

- Yoast SEO
- Rank Math
- SEO SIMPLE PACK
- SEOPress
- The SEO Framework
- All in One SEO
- Cocoon テーマ（前身テーマ Simplicity のキーへのフォールバックを含む）

いずれも**実際のプラグインのソースから確認したキー**です。推測でメタキーを読むことはしていません。誤ったキーを 1 つ書けば、noindex にしていないページが黙って目次から消えるためです。

上記以外は `rapls_sitemap/is_noindex` フィルターで追加できます。

```php
add_filter( 'rapls_sitemap/is_noindex', function ( $noindex, $post_id ) {
	return $noindex || 'yes' === get_post_meta( $post_id, '_your_seo_noindex', true );
}, 10, 2 );
```

なお読み取るのは**記事ごとの noindex 設定**です。「この投稿タイプ全体を noindex にする」といったサイト全体の既定値は対象外で、それは「除外するカスタム投稿タイプ」で指定してください。

## よくある質問

### 大量の記事があっても大丈夫ですか

「1 リストあたりの件数」で上限を設定できます。初期値は 2000 件です。サイトマップは全投稿タイプの全件を一度に取得する構造上、大規模サイトではこのクエリがメモリ不足を起こすため、上限は安全弁として設けています。投稿・ターム・投稿者の 3 つのクエリすべてに効きます。

上限に達した場合は「先頭の N 件のみ表示しています。」と出力に明記されるので、黙って一部が欠けることはありません。0 を指定すると上限なしになります。

### カテゴリーの横に出る件数は何の数ですか

そのカテゴリーの下に**実際に表示されている項目の数**です。カテゴリーが保持している記事数ではありません。除外設定・noindex の除外・件数上限がそれぞれ表示内容に影響するため、保持数を出すと「12件」と書いてあるのに 8 件しか並んでいない、という食い違いが起きます。

「カテゴリーのみ」表示のときは並べる項目がないので、カテゴリーが保持する記事数を表示します（子カテゴリーを入れ子にしている場合は子の分も含みます）。

### 五十音順に並べられますか

読みを記録したカスタムフィールドがあれば可能です。「並べ替えの基準」で「カスタムフィールド」を選び、フィールド名を指定してください。

「タイトル」順はデータベースの照合順序に従うため、かなと英字は正しく並びますが漢字は正しく並びません。大阪が「おおさか」と読むという情報は、WordPress のどこにも保存されていないためです。

### 箇条書きに国旗の絵文字を使えますか

選べますが、**Windows は国旗の字形を持っていません。** そのため Windows で閲覧している人には 🇯🇵 が「JP」のように 2 文字のアルファベットで表示されます。絵文字ピッカーの「旗」タブにも同じ注意を表示しています。🏁 🚩 🏳️ 🏴 🎌 は通常の記号なので、どの環境でも意図どおり表示されます。

### 多言語サイトで使えますか

WPML と Polylang に対応しています。設定は不要です。どちらも投稿とタームのクエリを現在の言語で絞り込むため、言語ごとに正しいサイトマップが出力されます。本プラグインはクエリフィルターを無効化しません。描画結果のキャッシュも言語ごとに分かれます。

### 追加 CSS は誰が編集できますか

`unfiltered_html` 権限を持つ利用者のみです。シングルサイトでは管理者、マルチサイトではネットワーク管理者に限られます。`manage_options`（設定画面を開ける権限）では編集できません。マルチサイトではサイト管理者もこの権限を持つためです。追加 CSS はそのまま出力されるので、WordPress が同種の用途に用意している権限に合わせています。

## Development

### Requirements

- WordPress 6.0 以上
- PHP 7.4 以上
- 外部依存なし（Composer は任意。PSR-4 オートローダーを同梱しています）

### コマンド

```bash
bin/run-tests.sh              # 全スモークテスト（最初の失敗で停止）
bin/run-tests.sh --all        # 最後まで実行して集計
php tests/smoke-tree.php      # 単体で実行

bin/build.sh                  # -> ../rapls-sitemap.zip（WordPress.org 用の構成）

php bin/make-pot.php          # languages/rapls-sitemap.pot を再抽出
msgfmt -o languages/rapls-sitemap-ja.mo languages/rapls-sitemap-ja.po
php bin/make-json.php         # PO -> ブロックエディター用 Jed JSON
```

PHPUnit・Jest・lint・JS/CSS のビルドツールはいずれも使いません（rapls-* ファミリー共通の方針です）。テストは `tests/smoke-*.php` を `php` で直接実行する形式で、WordPress を読み込まずに動きます。
